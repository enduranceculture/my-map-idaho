# Oakridge / Westfir Hot Springs

This folder is shared MYDAHO geography, not user profile data.

- Every verified improvement here becomes available to every MYDAHO user.
- Personal Hit / Yet / visit history is stored separately per account.
- Access and closure fields are dated facts or source-backed research, never a live guarantee.
- Private or currently inaccessible sites may remain in the shared layer when showing them prevents false assumptions about public access.

Current V1 coverage:
- McCredie Hot Springs
- Wall Creek Warm Springs (Meditation Pool)
- Kitson Hot Springs (private / not yet public)
